# Tada Marketplace Category Taxonomy

**Canonical locale:** English (`en`). UI labels default to the English labels below; keep every `slug` stable and add translated labels in locale files rather than translating stored category values. Korean descriptions and common item terms remain here as editorial and matching references.

## Localisation Rules

- Store `category_slug` and `subcategory_slug`, never a translated label.
- English is the fallback display locale.
- Add translations by locale code, for example `ko`, `ja`, `zh-Hans`, and `es`, using the same slug keys.
- Keep title-matching keywords separate from UI translations. Matching can include English and Korean aliases while the selected UI label remains English.
- Do not use machine-translated slugs or change an existing slug after listings have been published.
